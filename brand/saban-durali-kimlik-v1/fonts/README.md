# Yazı tipleri

İki değişken yazı tipi, ikisi de SIL Open Font License 1.1 ile ücretsiz ve ticari kullanıma açık:

- **Archivo** (ağırlık 100–900, genişlik %62–125): logo yazısı, başlıklar, metin. https://fonts.google.com/specimen/Archivo
- **Martian Mono** (ağırlık 100–800, genişlik %75–112,5): sayılar, kare adresleri (F2), bölüm çipleri. https://fonts.google.com/specimen/Martian+Mono

Google Fonts CSS bağlantısı (ikisi birlikte, bütün ağırlık ve genişlikler):
https://fonts.googleapis.com/css2?family=Archivo:wdth,wght@62..125,100..900&family=Martian+Mono:wdth,wght@75..112.5,100..800&display=swap

Next.js’te `next/font/google` ile yükleyin (`SABAN_DURALI_BRAND_SYSTEM.md`, bölüm 4). Masaüstü (Word, PowerPoint, Figma) için buradaki TTF dosyalarını kurun.
Logo yazı tipiyle yeniden yazılmaz; her zaman `logo/` dosyaları kullanılır.
